- yusAgent: skills and MCP servers changed during a conversation now apply from the next message, without a new conversation. Before each prompt, the session compares the skills and generic MCP servers its model was told about with what the disk holds, and announces any difference at the end of the history (`[skills-changed]`, `[mcp-changed]`); the system prompt and the tools stay those of the opening, so the prompt cache keeps its prefix. A Python skill added during a conversation is announced with the steps that load it into the running kernel. The ACP bridge serves the extension's skills, MCP and settings screens (`_yus/skills/*`, `_yus/mcp/*`, `_yus/settings/*`) and publishes each announcement as a `_yus/notice`; `permissions` and the settings frozen per conversation are refused. `compaction.enabled` saved in the settings applies to the running session at its next compaction decision.
