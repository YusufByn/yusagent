- yusAgent: after a binary change, the ACP mode (the VS Code extension) no longer keeps using a daemon started by another yusagent build. It compares the daemon's version with its own and replaces that daemon when nothing holds it: no client attached (after a 3 s wait), no turn, bash, tool, subagent or quota park, and, as for an idle passivation, no background `bash()`, armed cron or heartbeat, or RLM work. Otherwise it refuses to start, names both versions and asks for `yusagent shutdown`. A daemon from before this check cannot tell what its sessions hold, so any live session keeps it. The TUI keeps its behavior. The refusal of a conversation the daemon cannot check now says the daemon may be from another build and gives both versions.
