- yusAgent: the ACP bridge now serves resume and history for the VS Code extension. `session/new` and `session/load` answer with the session's file (`saved { sessionId, path }` in the bridge `_meta`); `session/load` replays the conversation of the session opened with `--resume`, turn by turn, before its answer; `session/list` lists the folder's conversations; `_unharnessed/sessions/delete` stops a conversation's session in the daemon, then deletes its file and kernel snapshot. A conversation open in another window is not loaded twice. The usage journal now records fingerprints of the system prompt and tools (`prefix`) and journals one `resume_prefix_change` invalidation when a resumed session's prefix changed (a skill, an MCP server or an AGENTS file changed in between). Nothing changes in what the model sees.
