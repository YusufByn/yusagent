- yusAgent: new `existingTestsRule` setting, off by default. When it is `true`, the version-2 system prompt gets one more rule, right after the rule on the smallest change: "Existing tests encode expected behavior: if one fails after your change, fix your change; do not edit, skip or exclude that test unless the task explicitly asks to change the behavior it checks." Off, the prompt is unchanged, byte for byte. The setting is frozen per session in `yaRequest`, always written (`true` or `false`), so new sessions now carry `"existingTestsRule": false` by default; a session with `promptVersion: 1` and `existingTestsRule: true` is refused at start.
