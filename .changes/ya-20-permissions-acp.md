- yusAgent: in ACP, a manual session asks before each tool call with `session/request_permission` (allow once or reject once); a declined call does not run and the turn stops, as does `session/cancel` or a disconnect while a request waits. The new `permissions` session option switches the session between `manual` and `auto` (no sandbox yet); each decision and each switch is journaled in the session file. Sessions created by the TUI stay refused in manual until the TUI asks.
