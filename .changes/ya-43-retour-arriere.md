- yusAgent: in the VS Code extension, a message already sent can be changed and sent again: clicking it brings it back to the message box, and sending takes the conversation back to before that message (the turns after it leave the model's context, and stay in the session file on a branch of their own). The model is told in one fixed line that the conversation went back and that its Python kernel kept its state. Files on disk are not restored yet, and after a restart or a resume from the history only new messages can be changed. ACP: `_yus/session/rewind { sessionId, to }`, with `to` from the `rewindTo` of a prompt's `turnStart`; the next model call journals `invalidation: {"cause": "rewind"}`.
