- yusAgent: `await bash(cmd)` now waits up to 30 seconds by default before it returns a snapshot of a command still running (was 1 second). New `bashWaitSeconds` setting (whole seconds, at least 1; `1` restores the previous behavior). The value changes the `await bash(cmd)` line of the system prompt and the kernel bootstrap; the request body is unchanged. It is frozen per session in the session file header (`yaRequest`): a resumed session keeps it and warns when the current settings differ, and a session created before the setting keeps 1 second, so its prompt does not change on resume.
