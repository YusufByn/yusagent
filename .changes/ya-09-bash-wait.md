- yusAgent: new `bashWaitSeconds` setting, how long `await bash(cmd)` waits before it returns a snapshot of a command still running (whole seconds, at least 1; unset is 1 second, as before). Another value changes the `await bash(cmd)` line of the system prompt and the kernel bootstrap; the request body is unchanged. Frozen per session in the session file header (`yaRequest`, written only when not 1): a resumed session keeps it and warns when the current settings differ, and a session from before the setting keeps 1 second.
