- yusAgent: new `codexSessionIdHeader` setting, off by default. When it is `true`, requests to the ChatGPT subscription provider (`openai-codex`) carry a `session-id` header set to the session id, as Codex CLI sends for cache affinity, next to the existing `session_id` header. Other providers never get it. The request body and the prompt are unchanged; the setting is frozen per session in `yaRequest`, always written (`true` or `false`), so new sessions now carry `"codexSessionIdHeader": false` by default.
