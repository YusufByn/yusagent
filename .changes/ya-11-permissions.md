- yusAgent: tool calls need permission. The new global setting `"permissions"` (`~/.yusagent/settings.json` only; a project's `.yusagent/settings.json` is not read for it) is `"manual"` by default: every tool call (`python_repl` cell, `apply_patch`) is confirmed before it runs, a declined call does not run, its result reads `[permission-denied] The user declined this cell; nothing was executed.` and the turn stops; each decision is journaled in the session file. `"auto"` runs tool calls without confirmation and prints a warning on stderr, since there is no sandbox yet.
- yusAgent: a manual session that cannot ask (`-p`, RPC, and the daemon until ACP and the TUI ask) is refused at startup, before any model request, with the exact line to add to the global settings. The system prompt, tools and model requests are unchanged.
