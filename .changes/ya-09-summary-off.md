- yusAgent: `reasoningSummary` now defaults to `"off"`: OpenAI Responses requests (Codex, OpenAI, Azure) no longer carry `reasoning.summary`, as Codex CLI does for `gpt-6-luna`. Reasoning blocks keep their signature but carry no text, so no reasoning is shown in the TUI or over ACP unless `reasoningSummary` is set to `"auto"`. The smoke-bench A/B behind this change measured `gpt-6-luna` only (about 2.9 s less fixed latency per reasoning call). Existing sessions keep what they were sent with: a session header with `yaRequest` keeps its value, and one written before the field (with frozen YA-03 tools) stays `"auto"`; a session from before YA-03 takes the current settings, like its tools.
