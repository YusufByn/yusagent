- yusAgent: the text of a Python cell is capped at `kernel.maxOutputChars` characters (default 40 000; `0` disables), keeping its start and end and saving the full output to a file named in the result; a cell that crashes the kernel restarts it at once and ends with a notice (state restored from the last successful cell, cell not re-run); the kernel gains `read(path, offset, limit)` with line numbers and `bash(..., env={...})`.
