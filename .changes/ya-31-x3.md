- yusAgent: the VS Code extension shows its skills, MCP and settings screens on the ACP bridge's `_yus/*` methods. A change reaches the agent with the next message, with a line in the chat above that message; nothing waits for a restart. The permissions label of the message box opens a menu to switch the conversation between manual and auto. `_yus/settings/get` gives the defaults that apply to unset keys (retries, provider failover, usage-limit pauses, compaction).
