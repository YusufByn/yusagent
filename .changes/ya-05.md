- yusAgent: optional masking of old `python_repl` outputs (`"masking": {"enabled": true}`, off by default): outputs older than `window` turns (10) are replaced in the request by a placeholder that names `from rlm.masked import tool_output`, in steps of `step` turns (5) so the prompt prefix changes at most once per step; short outputs, images, the last failed output, the last failed test run, the last run of each diagnostic tool, outputs about files being edited and the last plan read are never masked. The session file keeps every output; a step that changes the masked set is journaled as an `invalidation` in `<id>.usage.ndjson`. A cell that reads a failed `bash()` result now records `bashFailedExit` in its tool-result details.
