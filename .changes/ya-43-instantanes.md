- yusAgent: workspace snapshots for going back to an earlier message (ACP bridge). Before each prompt of the bridge's client and at the end of every turn, the workspace is snapshotted into a shadow git repository under the agent directory (one per workspace, never the user's repository: no commit, branch or stash there), with the workspace's `.gitignore` (a default list without one), files over 8 MiB left out, and snapshots off with a message over 20000 files or 512 MiB, or without git. ACP: `_yus/session/restore_preview { sessionId, to, path? }` lists what a restore would change, the files changed outside the agent since its last turn and the files not covered; `_yus/session/restore { sessionId, to, files, conversation, force? }` restores the files (refused over changes outside the agent unless `force`; the state just before is kept), the conversation, or both, and the model is told in one fixed line. Only the bridge's own git may write the snapshots (the secret guard refuses the kernel). Snapshots older than 30 days, and those of deleted conversations, are removed. After a rewind, the conversation's new branch now survives a restart right away.
