- yusAgent: `bash(cmd, timeout=...)` stops a command still running after `timeout` seconds (SIGTERM to its process group, then SIGKILL 5 s later); a line in its output and its `[bash-done]` notice ("Killed: still running after its N s timeout.") give the reason. `timeout=None` sets no limit. Without the argument there is no limit for now; a persistent shell has none by default, and an explicit limit applies to it too.
- yusAgent: in daemonless sessions (`-p`, RPC), `[bash-done]` notices that arrive after the agent finished its turn wait for the other running commands, then wake the model once with all of them (at the end of the last command, or after `bashNoticeBatchSeconds`, 120 by default; `0` restores one wake per notice). A notice that arrives while the agent works still joins its next model call. The system prompt, tools and request parameters are unchanged.
