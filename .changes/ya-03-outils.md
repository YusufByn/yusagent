- yusAgent: on the Codex model family (`gpt-6.1-terra` and the other models of Codex's `models.json`, served by OpenAI or Azure on the Responses API), edits go through Codex's freeform `apply_patch` tool by default (`editTool: "kernel"` keeps `edit()` in the kernel); a patch that touches a path outside the session's working directory is refused whole. `shellTool: "native"` replaces the kernel's `bash()` with Codex's `exec_command` and `write_stdin` tools. Both settings are frozen per session in the session file header: a resumed session keeps its tools and warns when the current settings differ. Explicit native settings outside the Codex family, and a model change to another family during a session, are refused. The system prompt documents `read()`, `bash(env=...)` and the output cap.
