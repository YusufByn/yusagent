- yusAgent: a Codex session's WebSocket now answers the server's keepalive pings while it waits between requests (for example during a long `bash()` command). The server no longer closes it with `1011 keepalive ping timeout` after about 75 s of silence, and the session no longer falls back to SSE with full request bodies until it ends. A connection closed while waiting is replaced by a fresh WebSocket on the next request, and data frames received outside a request are counted in a `websocket_idle_messages_ignored` diagnostic instead of being read as part of the next request.
