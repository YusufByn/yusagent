- yusAgent: on macOS, every process yusAgent launches (the kernel, `bash()`, git, package installs, editors, the browser opener…) runs under a Seatbelt profile that refuses the credential files (`auth.json`, `models.json`), the daemon's sockets, the running binary and LaunchServices; `PRIME_AGENT_SECRET_GUARD=off` turns it off (with a warning). Where the guard has no mechanism yet (Linux, until PR C), the kernel refuses to start unless it is turned off.
