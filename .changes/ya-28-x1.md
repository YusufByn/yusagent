- yusAgent: the VS Code extension now resumes and lists conversations. "Restart" brings a conversation back from its file (turns the agent ran while the chat was closed included), the history menu lists the folder's conversations and opens or deletes one (a delete also stops its session in the daemon), and a new conversation left empty is closed and deleted, also when VS Code closes or reloads with it in the panel (the bridge deletes it as it ends, unless another window holds it). A conversation open in another window is not opened twice: the panel says why, with a Restart button. A daemon started by an older yusagent, which cannot tell, refuses the load and asks for `yusagent shutdown`. A turn the agent is still running when a conversation is loaded shows as running, and a message typed meanwhile waits for its end.
