- yusAgent: new `reasoningSummary` setting, `"auto"` (default, requests unchanged) or `"off"`, which removes `reasoning.summary` from OpenAI Responses requests (Codex, OpenAI, Azure). With `"off"`, reasoning blocks keep their signature but carry no text, so no reasoning is shown in the TUI or over ACP. The setting is frozen per session in the session file header (`yaRequest`), daemon sessions included: a resumed session keeps it and warns when the current settings differ, a fork keeps the value of its source, and a session from before the setting (or with an unreadable value) runs with `"auto"`.
