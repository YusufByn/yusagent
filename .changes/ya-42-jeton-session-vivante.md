- yusAgent: a running session now picks up a refreshed or replaced credential: before each model request the worker re-reads `auth.json` (a `/login` in another window, a key rewritten on disk, a token another process refreshed), and an expired subscription token (ChatGPT, Claude, Copilot, xAI) is refreshed on the spot, once across all running sessions, instead of failing every turn with "sign-in expired" until a reconnect. A token still valid locally but rejected by the provider (401) is not force-refreshed.
